# Network Connectivity Troubleshooting Guide

## Scenario

A user reports that they cannot access the internet or connect to network resources.

## Objective

Identify and resolve common network connectivity issues to restore access to the network and internet.

## Troubleshooting Steps

1. Confirm whether the issue affects one device or multiple devices.
2. Check that the network cable is connected or that Wi-Fi is enabled.
3. Verify that the device has a valid IP address.
4. Test connectivity by pinging the default gateway.
5. Restart the network adapter or reconnect to the Wi-Fi network.
6. Restart the router or switch if appropriate.
7. Test internet access by opening a website.
